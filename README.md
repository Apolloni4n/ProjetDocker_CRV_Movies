# Conception et déploiement d'une application Web orientée données et API

Nous avons réalisé une application Web permettant d'avoir un catalogue de films dynamique.

## Table des matières

- [Utilisation](#utilisation)
- [Auteurs](#auteurs)

## Utilisation

Assurez-vous d'avoir docker, kubectl et minikube installés.   
Placez-vous dans le dossier racine, exécutez la commande './run.sh'
Il suffit maintenant de se connecter à l'adresse IP qui sera affichée à la fin du démarrage
